This directory contains genetic test report layouts, used when listed in structure_selection.enabled_structures in pipeline.yml. Any template may be paired with any profile: they convey structure and register only, and the prompt instructs the generator to substitute the profile's own modality, anatomy and findings.

-  DNA, FISH, MLPA and PCR: near-verbatim variations of real reports, keeping their layout, typos and quirks, with dates shifted and names and locations redacted.
