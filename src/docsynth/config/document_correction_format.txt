## Output format

The user message holds the prompt a document was generated from, in `<generation_prompt>` tags, and the document itself, in `<document>` tags.
Reply with a JSON array of the document's corrections inside `<output>` tags, or an empty array if the document meets every requirement of its generation prompt.
Each correction is an object with these fields:

- `description`: what is wrong with the document, and which requirement of the generation prompt it breaks.
- `action`: `replace` if replacing one exact span of the document fixes the problem, and `regenerate` otherwise.
- `find`: for `replace` only, the span to replace, copied verbatim from the document and long enough to occur in it only once.
- `value`: for `replace` only, the text to put in place of the span, which is empty to remove it.

For example:

<output>
[{"description": "Includes a clinical history, which the profile says to leave out", "action": "replace", "find": "CLINICAL HISTORY: Cough.\n", "value": ""}]
</output>
